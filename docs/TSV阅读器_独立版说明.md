## 1. 用途

现场用系统「文件」或任意文件管理器找到 `.tsv` 记录文件后，直接选择「打开方式 → TSV 阅读器」，即可在 PDA 上查看，不用连电脑、不用 Excel。

适合：

- 查看 `/sdcard/zhuanggui/装柜记录/日期/柜号.tsv`
- 查看回收站里的 TSV
- 查看 U 盘 / 下载目录里拷来的 TSV
- 快速搜索某个条码、柜号或任意内容

只读查看，**不会修改、删除或上传原文件**。

## 2. 安装

### 方式 A：文件管理器安装

把 `成品出库_TSV阅读器_v1.0.0.apk` 拷到 PDA，点按安装。首次安装需允许「安装未知应用」。

### 方式 B：数据线 adb 安装

```powershell
adb install -r 成品出库_TSV阅读器_v1.0.0.apk
```

APK 使用与主 App 相同的 release keystore 签名；以后升级阅读器需使用同一 keystore，否则不能覆盖安装。

## 3. 打开 TSV 的两种方式

### 3.1 从文件管理器打开（推荐）

1. 打开系统「文件」。
2. 进入 `/sdcard/zhuanggui/装柜记录/2026-10-21/` 这类目录。
3. 点 `CSGU7441210.tsv`。
4. 在「打开方式」里选 **TSV 阅读器**（可选「仅此一次」或「始终」）。

应用会直接读取文件管理器传入的 `content://` 或 `file://` 地址。

### 3.2 在阅读器内选择文件

1. 桌面打开 **TSV 阅读器**。
2. 点「选择 TSV 文件」。
3. 在系统文件选择器中找到 `.tsv` 文件并确认。

如果文件管理器没有弹出「打开方式」，用这种方式即可，不依赖文件管理器的 MIME 识别。

## 4. 界面与操作

| 区域 | 说明 |
| --- | --- |
| 顶部 | 当前文件名；右侧「打开文件」可换一个 TSV |
| 汇总 | 共 N 条记录、N 列（第一行作为表头，不计入条数） |
| 搜索 | 输入条码、柜号或任意内容，实时过滤；右侧「清除」恢复全部 |
| 记录卡 | 大字显示条码、时间、柜号、操作员；有「结果」列时显示结果标签（正常 / 辅助 / 异常；旧文件也兼容重复 / 串号 / 超量），v1.10.4 四列文件不显示结果 |
| 点按记录 | 弹出详情，显示所有列；可「复制条码」或「复制整行」 |
| 滚动 | 列表按文件原顺序显示，可一直滚到本条柜最后一条 |

搜索结果会显示「匹配 N 条」，避免误以为文件变短。

## 5. 支持范围

- 文件格式：`.tsv`（制表符分隔的文本）；`.txt` 也可打开查看
- 记录格式：兼容主 App **v1.11.1 五列**（时间/柜号/条码/操作员/结果）、v1.10.4 四列和旧版六列；无「结果」列的文件不显示结果标签
- 编码：UTF-8（含 BOM）、UTF-16 LE/BE（含 BOM）、GBK / GB18030 自动兜底
- 换行：LF、CRLF；末行没有换行也可以
- 字段：支持双引号包裹、字段内 Tab / 换行、`""` 转义
- 文件大小：最大 20 MB（现场单柜 TSV 通常只有几十 KB）
- 表头：**第一行固定作为表头**；后续行是数据
- 权限：通过文件管理器 `content://` 打开时不需要存储权限；`file://` 打开时首次会申请「读取存储」权限

不支持：`.xlsx` / `.xls`、编辑、批量导出、跨多个 TSV 搜索。需要按日期/柜号浏览、跨文件搜条码时，用主 App 的「扫码记录查看 → TSV 原文」。

## 6. 与主 App 内置 TSV 原文的区别

| 对比项 | 独立 TSV 阅读器 | 主 App「TSV 原文」 |
| --- | --- | --- |
| 安装 | 单独 APK，可只装阅读器 | 随主 App 安装 |
| 入口 | 文件管理器「打开方式」/ App 内选文件 | 主 App → 扫码记录查看 → TSV 原文 |
| 文件范围 | 当前打开的单个文件 | 按日期 / 柜号浏览，含回收站 |
| 搜索 | 当前文件内搜索 | 跨文件搜条码 |
| 改动文件 | 只读 | 只读 |
| 适合 | 现场快速核对某一份 TSV | 系统排查、跨柜查询 |

## 7. 常见问题

**Q：文件管理器里点 `.tsv`，没有「TSV 阅读器」选项？**  
A：先点「打开方式」而不是直接打开；仍没有时，打开 TSV 阅读器 →「选择 TSV 文件」。部分文件管理器把 `.tsv` 识别为未知类型，本应用已兼容常见 MIME 和 `*/* + .tsv 路径`。

**Q：提示「没有读取该文件的权限」？**  
A：在文件管理器里重新选择「打开方式 → TSV 阅读器」，让文件管理器重新授权；或改用 App 内「选择 TSV 文件」。

**Q：打开后中文乱码？**  
A：本应用会自动尝试 UTF-8 / UTF-16 / GB18030。若仍乱码，文件可能不是文本 TSV，或使用了少见的编码，请用电脑另存为 UTF-8 后再打开。

**Q：能改记录、删记录吗？**  
A：不能。阅读器只读；删除记录仍在主 App 的扫码记录页操作。

**Q：会联网上传吗？**  
A：不会。应用没有申请网络权限，文件只在本机读取。
