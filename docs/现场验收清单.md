## 一、装机与授权（新机必做）

- [x] 安装 APK（`成品出库_v1.12.0.apk`），桌面出现「成品出库」
- [ ] 首次点【出库扫码】→ 按提示授予「所有文件访问」；回首页红字提示消失
- [ ] 电池优化白名单：`adb shell cmd deviceidle whitelist +com.zhuanggui.pda`
- [x] 「扫码记录查看 / 回收站 / 规则库」页面可正常打开、数据可滚动
- [x] 记录目录写入：首页提示「记录自动保存：/sdcard/zhuanggui/装柜记录/」，扫码后该目录下能看到当天柜号 .tsv
- [ ] 拉出 U 盘/连接电脑后，/sdcard/zhuanggui 下的文件可正常复制打开（Excel 不乱码）

## 二、扫描设置与扫码链路（新机必做）

- [x] 首页底部点「扫描设置（新 PDA 装机必看 / 扫码自检）」

- [ ] ② 点「一键打开『扫描配置』」→ 能打开 PDA 自带扫描工具

- [x] ④ 用扫码枪扫任意条码 → 页面显示条码内容、来源广播与时间

## 三、WiFi 同步与多 PDA（v1.10.0 默认下线，需时由项目组开启）

> 当前版本首页没有「WiFi 同步」入口、后台也不再周期同步；下面几条在项目组恢复同步开关后才需要验收。

- [ ] 电脑端双击 `装柜同步服务.exe` → 浏览器自动打开 `http://127.0.0.1:8000/`
- [ ] PDA「WiFi 同步 → 扫描配对码」扫电脑二维码 → 提示配对成功（显示服务器地址与设备号）
- [ ] 扫 1~2 码 → 5 秒内电脑网页「最近收到的扫码记录」出现该码，来源 PDA 正确
- [ ] 网页「PDA 设备」能看到该 PDA → 点「改名」为现场名称 → 记录文件夹同步改名
- [ ] 断网扫码 3 码 → 恢复网络后自动补传，电脑端计数一致
- [ ] 「下载记录 ZIP」解压后目录结构为 `<PDA名>/装柜记录/日期/柜号.tsv`
- [ ] 记录删除/撤回 → 电脑端对应文件同步进入/移出 `回收站`
- [ ] 规则库：PDA「上传本机」→ 网页 rev+1；网页「下载 Excel → 改一行 → 上传覆盖」→ PDA「下载并覆盖本机」后内容一致，且 PDA 侧有 `规则库_同步前备份_日期.xlsx`

## 四、装柜主流程（v1.7.0 起）

- [x] 流水号范围：给规则填最小/最大值 → 范围内正常、范围外报「条码流水号超出规则范围」；留空一侧 = 该侧不限
- [x] 末尾流水号：条码 `ASV12SDFWG05455056$`，填「末尾位数」3 → 核对 056；位数填错（如 4）应取 5056 并报串号
- [x] 流水号补录：规则行点「设范围 / 流水 …」→ 填范围保存；扫码页摘要同步；点「清除」恢复不限
- [x] 规则列表位置：本柜条码规则在【装柜】按钮下方；增删规则时上方设置区不位移
- [x] 计划回显：从扫码页返回 → 显示上次计划值；输入前面已有的柜号 → 显示该柜已存计划
- [x] 已扫码数量：与工号栏同款只读框，点按不可改；随今天正常扫码数变化
- [x] 工号下拉：点右侧箭头可选 A/B/C/D；仍可扫工牌/手输
- [x] 震动和声音设置：正常/非正常两组分别设声音开关与震动强度（关/弱/中/强），强杀重开保持；语音朗读开关关闭后不再播报
- [x] 语音朗读：正常扫码读「已扫码，N」（10→十、25→二十五、256→二百五十六）；辅助码/忽略读「辅助码」；报警不朗读
- [x] 规则库：按型号分组；同型号多条规则各自设四个开关；从规则库选择到本柜后开关跟随
- [x] v1.11.2 整组选择：从规则库选择时按型号展示，同一型号有 2 条规则 → 选 1 次型号一次加入 2 条；部分已在本柜时只补加剩余（单测 6 项）
- [x] v1.11.0 新增型号：保存后自动打开「添加规则」；型号可连续添加多条前缀；弹窗内扫码枪可把条码填入前缀栏（可再删减）
- [x] v1.11.0 默认装柜数量：只在型号上维护 1 个（新增/编辑型号），其下所有规则共用；设置页计划为空时从规则库选择自动带出，已手工填写不覆盖
- [x] v1.11.0 保存到规则库：当前多条规则 + 计划按型号保存 → 回设置页用「从规则库选择」载入一致；同名型号覆盖其原规则，其他型号不受影响
- [x] v1.11.3 保存后定位：保存成功点「去规则库查看」→ 自动展开并滚动到刚保存型号；也可从设置页进「规则库管理」自动定位（2026-10-26 真机验证）
- [x] v1.12.0 重复校验：普通计数码同前缀跨型号保存被拦截；可重复扫 / 辅助码 / 查历史串号 / 忽略码同前缀可保存到多个型号；同一型号内仍拦截重复（单测覆盖）
- [x] 忽略：勾「可重复扫 + 忽略」→ 反复扫不报警、不产生记录、不计数，语音报「辅助码」；记录页 / TSV 均无该码
- [x] 迁移：v1.6.0 真库升级 v11 后柜数 / 规则数 / 记录数不变，规则默认值 = 旧行为；v1.11.0 真库升级 v16 后同样保留；2026-10-26 迁移测试 8 项真机通过（合成库，非现场真库）；v1.12.0 的 v16→v17 已加测试，待真机补跑
