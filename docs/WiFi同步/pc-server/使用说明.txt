装柜 PDA 同步服务（Windows 免安装版）
========================================
版本：v1.3（配套 成品出库 App v1.8.0 及以上，规则库同步需 v1.9.0+）
文件：装柜同步服务.exe（无需安装 Python）

一、首次运行
1. 把整个文件夹复制到电脑（建议 D:\装柜同步服务\），路径尽量不含特殊符号。
2. 双击「装柜同步服务.exe」：
   - 首次 Windows 防火墙弹窗：勾选「专用网络」→ 允许访问。
   - 浏览器会自动打开 http://127.0.0.1:8000/，页面显示配对二维码、令牌和最近记录。
3. 浏览器没自动打开时，手动访问 http://127.0.0.1:8000/。
4. 电脑与 PDA 必须连同一个 WiFi / 路由器（路由器不要开「AP 隔离」）。

二、PDA 配对
1. PDA 首页 →「WiFi 同步」→「扫描配对码」，用扫码枪扫电脑页面上的二维码。
2. 扫码枪不支持二维码时：点「手动输入」，输入  电脑IP:8000#令牌
   （IP 与令牌都在电脑页面顶部，例如 192.168.1.100:8000#K7F2QW9M）。
3. 配对成功后，历史待传记录会自动上传；以后每扫一码 5 秒内自动同步。

三、扫码记录保存在哪里
- 数据库：data\sync.db（所有记录，最终以此为准）。
- 记录表格：data\装柜记录\PDA名称\日期\柜号.tsv
  例：data\装柜记录\一号机\2026-10-20\ABC123.tsv
  格式与 PDA 本地 TSV 相同（时间、柜号、条码、操作员、结果；结果为正常/辅助/异常），
  Excel / WPS 可直接打开；同一台 PDA、同一柜号、同一天追加在同一文件。
- 删除 / 撤回的记录：data\回收站\PDA名称\日期\柜号.tsv（不会丢，只是移到回收站）。
- 双击「打开数据文件夹（记录表格）.bat」可直接打开表格目录。
- 服务启动时会按数据库自动重建表格文件；手工删掉表格后，重启服务即可恢复。

四、多台 PDA（命名 / 文件隔离）
1. 每台 PDA 首次同步后自动登记；电脑网页「PDA 设备」卡片显示设备号、最近同步、记录数。
2. 点「改名」改成现场名称（如 一号机、二号机、张三）；已有记录文件夹会一起改名。
3. 每台 PDA 的记录单独存放（见上），互不混合；网页「最近记录」右侧可按 PDA 筛选。
4. 「下载记录 ZIP」可下载某台 PDA 的全部记录 + 回收站，ZIP 内以 PDA 名称作为顶层目录。
5. 建议一个柜号固定由一台 PDA 扫描；如分两台扫同一柜，记录会分别在各自文件夹，电脑端不会自动合并，可给柜号加 -A/-B 后缀。
6. 规则库目前是所有 PDA 共用一份；如每台 PDA 需要不同规则，需另行扩展。

五、日常使用
- 保持黑色窗口开着 = 服务运行；关闭窗口 = 停止服务。
- 备份：先关闭服务，再复制整个 data 文件夹（数据库 + 各 PDA 表格 + 规则库备份）。
- 电脑 IP 建议在路由器做 DHCP 保留（固定 IP）；IP 变了需要在 PDA 重新配对。

六、开机自启（可选）
- 双击「开机自启（可选）.bat」，会在当前用户「启动」目录创建快捷方式；
  下次登录 Windows 自动启动服务。

七、防火墙（没弹窗或 PDA 连不上时）
- 右键「防火墙放行（管理员）.bat」→ 以管理员身份运行（只需一次）。

八、规则库同步（App v1.9.0+）
1. 电脑网页 http://127.0.0.1:8000/ 找到「规则库」卡片。
2. 点「下载 Excel（当前规则库）」→ 用 Excel/WPS 修改型号、前缀、四个开关、默认装柜数量（第 7 列，同一型号填同一个值）。
   - v1.12.0 起同一前缀可挂多个型号（适用于可重复扫 / 辅助码 / 查历史 / 忽略等特殊码）；普通计数码仍建议跨型号唯一。
3. 点「上传覆盖电脑端」选择改好的 XLSX（rev+1；覆盖前自动把旧快照备份到 data\规则库备份\）。
4. 各 PDA：首页 → WiFi 同步 → 规则库同步 →「刷新信息」→「下载并覆盖本机规则库」。
   - PDA 覆盖前会自动备份为 /sdcard/ZhuangGui/规则库/规则库_同步前备份_日期.xlsx
   - 已装柜的柜子使用各自规则快照，不受影响。
5. 也可以反过来：在任意 PDA 修改好规则后，点「上传本机」存到电脑，再让其他 PDA 下载。
6. 电脑端数据在 data\sync.db 的 rulelib 表（rev / 型号 / 规则 / 更新时间 / 来源）。

九、常见问题
- 页面打不开：8000 端口被占用（关闭占用程序），或安全软件拦截。
- PDA 连不上：确认同一网段、AP 未隔离、防火墙已放行、IP 是否正确。
- 表格被 Excel 占用：仍可继续同步（程序会稍后重写），关闭 Excel 后重启服务即可。
- 网页看不到某台 PDA：该 PDA 先完成一次同步；并确认使用同一配对令牌。
- 两台 PDA 记录混了：先确认网页「PDA 设备」名称不同；改名会自动迁移旧文件夹。
- 换电脑：复制整个文件夹（含 data），在 PDA 上重新配对。
- 卸载：关闭窗口，删除文件夹即可；data 里是数据，先备份再删。
- 更换端口：命令行执行  set SYNC_PORT=8001  后再运行 exe，PDA 配对地址端口同步改为 8001。
