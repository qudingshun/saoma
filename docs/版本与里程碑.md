## 一、App 版本历史（v1.0 → v1.9.1）

- **v1.9.1（versionCode 29，DB v14）**：**扫描设置引导 + 自检**——首页新增「扫描设置」入口页：① 检查系统「扫描配置/扫描服务」安装与启用状态（被停用可一键跳系统应用信息页启用）；② 一键打开系统「扫描配置」应用（按包名启动，另带显式 Activity 兜底）；③ 一键打开「开发者选项」查看本机实际广播名/键值；④ 扫码自检（模拟广播 + 显示最近收到的真实扫码内容/来源广播/时间）；⑤ 一键复制现场配置步骤。新 PDA 装机不再需要 IT 手工配置（东集开发者选项密码出厂默认 888888）。真机验证（CRUISE2 出厂机）：广播名 `com.android.server.scannerservice.broadcast`、键值 `scannerdata` 与 App 一致，广播 → App → 录入规则输入框全链路通；单测 41 项
- **v1.9.0（versionCode 28，DB v14）**：**规则库 WiFi 同步**——PDA「WiFi 同步 → 规则库同步」可「上传本机」（整库存到电脑，rev+1）或「下载并覆盖本机」（整库替换，覆盖前自动备份 `规则库_同步前备份_日期.xlsx`，备份失败取消；已装柜的柜子不受影响）；电脑网页增加规则库卡片：下载 Excel → 修改 → 上传覆盖电脑端（openpyxl 解析，支持型号/前缀/四开关；覆盖前旧快照自动备份到 `data\规则库备份\`）；电脑端 `sync.db` 新增 `rulelib` 表；PDA 显示电脑端/本机版本、条数、来源与「有新版本」提示；单测 41 项
- **电脑端 v1.3（配套 App v1.9.0，2026-10-20）**：多 PDA 管理——首次同步自动登记设备（默认设备号），网页「PDA 设备」改名/筛选/下载记录 ZIP；记录按 PDA 名称分目录 `data\装柜记录\PDA名称\日期\柜号.tsv`，改名自动迁移文件夹；旧版混合目录自动移入 `_旧版混合文件_*`；规则库仍为所有 PDA 共用一份
- **v1.8.3（versionCode 27，DB v14）**：规则库导入前核对——选文件后先显示「文件内 N 条、将新增 X 条 / 覆盖 Y 条（列出覆盖前缀）、新增型号数」，点「继续导入」才写入；取消不改规则库、不生成备份；确认后仍先自动备份当前规则库（带日期），备份失败整体取消
- **v1.8.2（versionCode 26，DB v14）**：规则库文件不覆盖——导出文件名带日期时间（同秒自动 `_2`）；**导入前自动备份**当前规则库，备份失败则取消导入；电脑端同步服务新增 TSV 落盘（与 PDA 同格式、UTF-8 BOM，Excel 直接打开），删除/撤回记录进回收站，启动时按数据库重建历史文件
- **v1.8.1（versionCode 25，DB v14）**：首页修复——「出库扫码」大按钮去掉默认投影、与下一按钮的间距 20→28dp，修复按钮阴影/背景压住「扫码记录查看」边框；电脑端服务新增 Web 管理页（二维码/令牌/最近记录）与免安装 EXE 打包脚本 `build_exe.ps1`
- **v1.8.0（versionCode 24，DB v14）**：可选 WiFi 同步（P0 配对 + P1 扫码记录回传）——首页「WiFi 同步」入口；电脑端同步服务（FastAPI + SQLite，源码 `docs/WiFi同步/pc-server/`，运行目录 `E:\saoma\saoma-sync`，纯局域网）；二维码/手输配对（配对即校验 token）；扫码后 5 秒合并上传、后台 15 分钟补传、断网缓存恢复后补传；软删除/撤回状态同步，`uid` 幂等；设置页显示待传条数、服务器时间、上次同步/错误；未配对或服务不可达完全不影响扫码；DB v13→v14（`scan_records.uid/syncedAt`，新增 `sync_state / sync_inbox`）；单测 37 项、迁移测试 7 项
- **v1.7.5（versionCode 23，DB v13）**：规则库「型号优先」维护——先「新增型号」，再在型号行点「＋ 添加规则」逐个添加前缀；列表默认折叠，点型号行展开规则（可改名/删除型号，删除型号连同其下规则删除）；导出改为 **XLSX**（型号名称 / 前缀 / 四个开关），列宽/表头已设置，导入按表头自动识别两种列序；空型号可导出/导入；DB v12→v13 新增 `rule_models`；单测 32 项、迁移测试 6 项
