## 一、App 版本历史（v1.0 → v1.11.0）

- **v1.11.0（versionCode 36，DB v16，2026-10-25）**：**连续装柜效率优化**——① 装柜完成返回设置页后，自动清空柜号 / 计划 / 规则 / 已扫数量，仅保留操作员，可直接录入下一柜；未装齐返回仍原样保留；② 规则库新增型号保存后**自动打开“添加规则”**，规则前缀输入框支持**扫码枪直接录入**（扫到真码后可删减为固定前缀），同一型号可维护多条规则，**默认装柜数量按型号只维护 1 个**，设置页从规则库选择时若计划为空/0 自动带出；③ 设置页新增**“保存到规则库”**，把当前规则（前缀 + 四个开关）和计划数量按型号保存，以后用**“从规则库选择”**载入；DB v14→v15→v16（默认数量从规则行归并到 `rule_models`，移除独立设置方案表）；单测 47 项、迁移测试 8 项
- **独立 TSV 阅读器 v1.0.0（versionCode 1，包名 `com.zhuanggui.tsvreader`，2026-10-22）**：新增单独安装的 TSV 阅读器，不依赖主 App：① 文件管理器点 `.tsv` →「打开方式 → TSV 阅读器」直接打开（兼容 `file://` / `content://`、常见 MIME 及 `*/* + .tsv 路径`）；② App 内「选择 TSV 文件」作为兜底入口；③ 表头 + 记录卡片、条码/柜号/任意内容搜索、点按详情、复制条码/整行；④ UTF-8（BOM）/ UTF-16 / GBK·GB18030 自动识别，支持 CRLF、引号字段、错列补齐，最大 20MB；⑤ 只读、无网络权限；兼容 v1.10.4 四列与旧六列 TSV；10 项单测；详见 [`TSV阅读器_独立版说明.md`](TSV阅读器_独立版说明.md)
- **v1.10.4（versionCode 35，DB v14）**：**TSV 明细精简为四列**——扫码记录文件改为 `时间 / 柜号 / 条码 / 操作员`，不再写完整码和判定结果；数据库仍保留完整码/结果，界面、统计、报警、回收站不受影响；启动时自动把旧六列/五列 TSV 迁移为四列（按表头取列，数据行一条不丢），主 App「TSV 原文」与独立阅读器同步兼容新四列和旧六列；无数据库结构变更
- **v1.10.3（versionCode 34，DB v14）**：**本柜记录显示全部**——扫码页「本柜记录」取消「最近 100 条」上限，改为读取本柜全部有效记录（现场单柜通常 ≤300 条），表头显示实际条数；记录逐条点按删除、正常记录三次确认等交互不变；无数据库结构变更
- **v1.10.2（versionCode 33，DB v14）**：**TSV 记录阅读器 + 扫码只走广播**——① 新增 App 内「TSV 记录阅读器」（扫码记录查看 →「TSV 原文」）：按日期/柜号浏览 `/sdcard/zhuanggui` 原始 TSV，单文件柜内过滤、顶部跨文件搜条码（含回收站），解决安卓 11 现场没有 Excel/电脑时无法核对原始记录的问题；② 扫码页移除 HID 键盘录入框，**只保留广播通道**（条码破损改用「手动录入」弹窗），修复扫描配置「广播 + 键盘」双开时一枪两条；③ 新增 `ScanDeduper`：同一次扳机 800ms 内同一串码只记一条（人工复扫 >1s 不受影响），OpLog 记「扫码去重」；④ 扫描设置页增加输出方式说明；单测 46 项（新增去重 4 项）
- **v1.10.1（versionCode 32，DB v14）**：**操作日志（试运行追溯）**——首页新增「操作日志」入口：记录启动（版本/存储状态/记录目录）、每枪扫码（柜号/条码/判定/来源/落盘成败）、落盘失败原因、删除/撤回/恢复/回收站清空、规则导入导出、崩溃栈；日志存 App 内部 `files/logs/oplog_yyyyMMdd.log`（每天一个、2MB 轮转，卸载才清），可一键导出到 `/sdcard/zhuanggui/日志/操作日志_日期_时间.txt`；写入走后台单线程，不阻塞扫码；崩溃时同步落盘最后几行
- **v1.10.0（versionCode 31，DB v14）**：**落盘根目录改为 `/sdcard/zhuanggui` + 写入兜底 + WiFi 同步默认下线**——① 记录文件改到 PDA 根目录 `zhuanggui`（装柜记录 / 回收站 / 规则库 / 装柜完成汇总.tsv），旧目录 `/sdcard/ZhuangGui` 首次启动自动迁移；② 修复「扫了 200 多件后提示存储权限、文件没落盘」——东集工业 ROM 用 legacy sdcardfs 挂载 /data/media，targetSdk 30+ 的应用拿不到 sdcard_rw 组权限（MANAGE_EXTERNAL_STORAGE 对 sdcardfs 无效），改为 **targetSdk 29** 后可正常写 /sdcard；③ 新增三层保险：主目录不可写时自动暂存 App 私有目录（首页橙条可「重新导出」）、扫码页显示真实失败原因、**启动时按数据库全量重建落盘文件**（把已扫但没落盘的记录补齐——真机 232 条已全部补回）；④ **WiFi 同步默认下线**（`AppConfig.SYNC_ENABLED=false`：首页入口隐藏、后台周期同步停用，代码全部保留，改常量重装即恢复）
