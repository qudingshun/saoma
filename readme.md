## 一、快速开始

**电脑端（一次即可）**
1. 解压 `装柜同步服务_v1.3_win64.zip` 到如 `D:\装柜同步服务\`，双击 `装柜同步服务.exe`（免 Python）。
2. 首次防火墙弹窗选「专用网络」→ 允许；建议再运行一次 `防火墙放行（管理员）.bat`。
3. 浏览器自动打开 `http://127.0.0.1:8000/`：配对二维码、令牌、PDA 设备列表、规则库、记录目录一览。
4. 电脑与 PDA 连同一 WiFi / 路由器（关闭 AP 隔离），建议给电脑固定 IP。

**PDA（每台）**
1. 安装 `成品出库_v1.11.3.apk`，首次点【出库扫码】按提示授予「所有文件访问」。
2. 首页底部点「**扫描设置（新 PDA 装机必看 / 扫码自检）**」：一键打开系统扫描配置、模拟广播自检、显示最近收到的真实扫码。
3. 首页 →「WiFi 同步」→ 扫描电脑上的配对二维码（或手动输入 `电脑IP:8000#令牌`）。
4. 扫一条码 → 5 秒内电脑网页可见；记录自动落到 `data\装柜记录\PDA名称\日期\柜号.tsv`。
5. （可选）安装 `成品出库_TSV阅读器_v1.0.0.apk`：在文件管理器点 `.tsv` →「打开方式 → TSV 阅读器」；详见 [`docs/TSV阅读器_独立版说明.md`](docs/TSV阅读器_独立版说明.md)。

## 三、校验与报警逻辑（出库扫码）

校验顺序：**规则前缀（串号）→ 同柜重复 → 查历史串号 → 辅助码 → 超量 → 正常**

| 情况 | 结果 | 反馈 |
|---|---|---|
| 条码不以任何规则前缀开头，或流水号超出该规则的最小/最大值（含「末尾 N 位」模式下取出的末尾 N 位数字） | 串号 SERIAL_MISMATCH | 红屏 + 蜂鸣 + 循环振动 |
| 同柜已扫过的条码（该规则未勾「可重复扫」） | 重复 DUPLICATE | 红屏 + 蜂鸣 + 循环振动 |
| 勾「查历史串号」的规则：条码已在其他柜记录里出现过 | 串号 SERIAL_MISMATCH | 红屏 + 蜂鸣 + 循环振动；提示"已于 xx 在柜 xxx 录入过" |
| 命中「不计入统计」规则的条码 | 辅助 AUX | 蓝屏 + 嘀声，只留痕不计数（可反复扫） |
| 勾「可重复扫」+「忽略」的规则：扫到该条码 | 忽略（按辅助码反馈） | 蓝屏 + 嘀声 + 语音「辅助码」；**不记录、不落盘、不计数**（双码机固定码减噪） |
| 已扫码正常数 ≥ 计划装柜数量 | 超量 OVER_LIMIT | 黄屏 + 提示音 + 循环振动 |
| 正常（计入统计的规则） | OK | 绿屏 + 嘀声，计数 +1 |

- 报警弹窗（重复 / 串号 / 超量）：点确认停止报警；重复 / 串号 / 超量弹窗还可一步删除该条
- 震动和声音设置（扫码页【震动和声音设置】，v1.7.0 由「报警设置」升级）：正常扫码 / 非正常扫码（串号·重复·超量）两组各自可设「声音开关」+「震动强度（关 / 弱 / 中 / 强）」；升级时沿用旧开关作为默认值。两者都关 = 仅界面提示（颜色 + 图标 + 弹窗文字）
- 语音朗读（同一弹窗内开关，默认开）：正常扫码读「已扫码，N」（自然读法：10 → 十、25 → 二十五、110 → 一百一十、256 → 二百五十六、300 → 三百）；辅助码 / 忽略读「辅助码」；重复 / 串号 / 超量不朗读
- 报警停止：弹窗确认 / 任意触屏 / 扫下一枪 / 删除记录 / 离开扫码页，另有 10 秒兜底自动停
- 报警三重编码：每种结果都同时有「颜色 + 图标 + 文字」，不只靠颜色区分
- **计数口径**：正常 / 串号 / 重复 / 超量均按「今天」（设备本地日期）统计；已删除记录与「忽略」的条码不参与；跨天再装不继承昨天计数

## 四、删除 / 撤回 / 回收站

- 删除一律**软删除**（`scan_records.deletedAt`），清空回收站前都可恢复
- 确认分级：重复 / 串号 / 辅助码 / 超量 = 1 步；**正常记录 = 3 步**；记录页单组 / 本日 / 批量 = 3 步；清空回收站 = 3 步
- 扫码页「撤回 / 前进」：撤销上一枪（软删）/ 恢复删除；换柜自动清空操作栈
- 回收站（记录页长按标题进入）：逐条撤回 / 全部撤回（恢复后重新计入统计）；清空 = 永久删除
- 落盘文件与 App 动作同步：整组删空 → 文件从「装柜记录」挪到「回收站」目录；撤回 → 挪回；部分删除 → 两侧各留一份

## 五、自动落盘（TSV）

- 路径：`/sdcard/zhuanggui/装柜记录/yyyy-MM-dd/柜号.tsv`（按日期分目录、按柜号分文件；已删除的进 `/sdcard/zhuanggui/回收站/`）
- v1.10.0：根目录改为 `/sdcard/zhuanggui`（旧目录 `/sdcard/ZhuangGui` 首次启动自动迁移）；主目录临时不可写时先写入 App 私有目录并在首页提示，可一键导回，记录不丢
- v1.10.2：App 内「扫码记录查看 → TSV 原文」可直接浏览/搜索这些原始文件（含回收站），现场不用连电脑、不用 Excel
- 列（Tab 分隔，v1.11.1 起）：`时间 ⇥ 柜号 ⇥ 条码 ⇥ 操作员 ⇥ 结果`；结果只写 `正常 / 辅助 / 异常`，具体串号/重复/超量原因仍保存在数据库和界面（操作员 = 设置页填写/扫入的工号，未填为空）
- 旧版四列/六列 TSV 在 App 启动时按数据库全量重建为五列，结果列自动补齐，记录条数不变；迁移前的旧文件如需留档，请先自行备份
- 装柜完成汇总：`/sdcard/zhuanggui/装柜完成汇总.tsv`（单文件累积，每装齐一柜追加一行；列：`完成时间 ⇥ 柜号 ⇥ 计划数量 ⇥ 正常 ⇥ 串号 ⇥ 重复 ⇥ 超量 ⇥ 记录总数 ⇥ 操作员`，计划数量 0 = 不限）
- UTF-8 带 BOM（Excel 打开中文不乱码）；同柜号回来继续追加；**每扫一码立即写入**
- 权限：Android 11+ 需「所有文件访问」（`MANAGE_EXTERNAL_STORAGE`，首次点【出库扫码】自动引导授权）

## 六、WiFi 同步与多 PDA（v1.8.0+，v1.10.0 起默认下线）

## 七、扫码对接与扫描设置（新 PDA 必做）

### 7.1 系统侧配置
解码由系统「扫描工具」（`com.seuic.scanner.activity`）完成——**不要禁用/停用它**（禁用 = 完全不能扫码）：

| 配置项（扫描配置 → 应用扫描配置 → 已配置应用） | 值 |
|---|---|
| 选择应用 | 成品出库（com.zhuanggui.pda） |
| 条码发送方式 | 广播 |
| 广播名称 | `com.android.server.scannerservice.broadcast` |
| 键值（extra） | `scannerdata` |
| 结束符 | ENTER |

实机链路：物理扳机 → 系统解码 → 广播送达 → App 收码 → 界面反馈 + TSV 落盘（全通）

### 7.2 App 内「扫描设置」页（v1.9.1）
- ① 系统扫描服务状态：安装 / 启用情况；被停用可一键跳系统「应用信息」页启用
- ② 一键打开系统「扫描配置」（按包名启动，另带显式 Activity 兜底）
- ③ 一键打开「开发者选项」查看本机实际广播名 / 键值（多数机型**不需要密码**；若弹出「输入开发者密码」，东集出厂默认 **888888**，部分机型「扫描设置」为 654321）
- ④ 扫码自检：模拟广播 + 显示最近收到的真实扫码（内容 / 来源广播 / 时间）
- ⑤ 一键复制现场配置步骤

### 7.3 App 端兼容与排查
- 兼容动作：`com.android.server.scannerservice.broadcast`｜`android.intent.action.SCANRESULT`｜`android.intent.action.BARCODE_CAPTURE`｜`urovo.rcv.message`｜`com.android.scanbroadcast.SCAN`
- 兼容键名：`scannerdata`｜`value`｜`barcode`｜`barcode_value`｜`scan_value`｜`data`｜`result`｜`BarcodeStr`
- 扫码通道（v1.10.2）：**只认广播**，扫码页不再放键盘录入框（避免「广播+键盘」双开时一枪两条）；条码破损时用扫码页「手动录入」弹窗手工输入。兜底组件 `HidScanField.kt` 保留给没有广播能力的机型，默认不启用
- 双通道防护：同一次扳机若仍因系统配置在 800ms 内到达两遍，`ScanDeduper` 只记一条（人工复扫 >1s 不受影响，OpLog 记「扫码去重」）
- 广播来源无法校验（系统限制，审计 13）：已知限制，收到即记 Log 留痕
- 收不到码排查：①「扫描配置 → 已配置应用」配置是否还在；②App 是否在前台（或进程存活）；③`adb logcat -s ScannerManager`（系统服务刷屏时改用 `adb logcat --pid <App进程号>`）

## 八、规则库导入 / 导出（XLSX）

- 导出格式（推荐）：`型号名称 | 前缀 | 可重复扫 | 计入统计 | 查历史串号 | 忽略 | 默认装柜数量`（是/否；默认数量 v1.11.0）
  - 每个型号可有多行（多个前缀）；空型号也导出为一行（前缀留空），导入时用于建空型号
  - 路径：`/sdcard/zhuanggui/规则库/规则库_yyyyMMdd_HHmmss.xlsx`（列宽已设置、首行冻结；同日/同秒自动追加 `_2`，不会覆盖旧文件）
  - 点「导入」会先自动备份当前规则库到 `规则库_导入前备份_yyyyMMdd_HHmmss.xlsx`，再按前缀覆盖；备份失败则取消导入，旧内容不丢
- 导入：支持 .xlsx / .xls / .csv / .txt / .tsv
  - 新 XLSX 按表头自动识别「型号名称在前」；旧文件（前缀在第一列）继续兼容
  - 只有型号、没有前缀的行 = 建空型号；首行表头自动跳过；前缀去空格转大写；同前缀去重
  - 回导 = 覆盖更新（按前缀）：带开关列的导出文件以文件为准；两列旧文件覆盖时保留库内原开关
  - 第 7 列「默认装柜数量」可选；旧六列文件没有该列时保留库内原默认数量，不误清空
  - 导入前会先显示「文件内 N 条、将新增 X 条 / 覆盖 Y 条」，确认后才写入（v1.8.3）
- 导入的规则默认「不可重复扫 + 计入统计 + 不查历史 + 不忽略 + 默认数量未设」；需要双码机/辅助码等设置时，导入后在规则库点「编辑」勾选
- 维护方式：**型号优先**（先建型号，再逐个添加规则；列表按型号折叠显示）；v1.11.0 新增型号保存后会自动打开“添加规则”，前缀可直接扫码录入，并可设默认装柜数量
- v1.9.2：规则前缀除字母数字外，**新增支持 `-` 与 `#`**（真实机型如 `HYW-T55`、`#9970`），导入不再被丢弃；前缀统一大写（仅大小写不同的型号会合并为一条规则）

## 十二、已知现象与注意事项

- 覆盖安装 = 应用进程重启（界面状态清空），**数据不丢**；卸载重装会清空 App 数据库，但 `/sdcard/zhuanggui/` 下的文件不受影响
- 仪器化测试 `connectedDebugAndroidTest` 跑完默认会卸载 App（清空数据库）——已在 `gradle.properties` 加 `android.injected.androidTest.leaveApksInstalledAfterRun=true` 保留安装；若曾误卸载，可用跑前快照经 `run-as` 回灌 `databases/zhuanggui.db` 恢复
- 冷启动约 4~7 秒（PDA 性能所限）
- 记录没落盘时的两种兜底：① 主目录不可写 → 自动暂存到 App 私有目录，首页橙条可「重新导出」；② 任何情况下都会在启动时按数据库重建缺失的记录文件
- 偶尔系统残留 "Application Error" 残影窗口（旧进程痕迹）：重启设备即消失，不影响使用
- 扫码触发以物理扳机为准：机内「扫描」软触发按钮经真机验证在 CRUISE2 上无效，已从界面移除；如未来要软触发需集成东集 SDK 绑定 ScanService
- 语音朗读使用 App 内置中文语音片段（assets/voice，16kHz PCM），**不依赖系统 TTS 引擎**；数字按自然读法拼接，超过 999 退回逐位；可在「震动和声音设置」开关
- 广播与键盘输出**只开一种**，否则同一枪会产生两份数据
- 同一柜号建议固定一台 PDA 扫；两台 PDA 扫同一柜时记录分目录存放、电脑端不自动合并
- 规则库目前所有 PDA 共用一份；需要按 PDA 独立时见优化建议 P0-4

| --- | --- |
| 首页提示「无法写入 /sdcard/zhuanggui」 | 点「出库扫码」按提示打开「所有文件访问」；或 系统设置 → 应用 → 成品出库 → 所有文件访问 开启；授权后回首页提示消失 |

| 规则库改了 PDA 没变 | PDA「WiFi 同步 → 规则库同步」→ 刷新信息 → 下载并覆盖本机规则库；已装柜的柜子不回溯 |
| 同一枪出现两条记录 | v1.10.2 起扫码只认广播，并做 800ms 同码去重；仍出现请到「操作日志」导出后发项目组（日志会记来源与「扫码去重」） |
| 想核对文件里到底写了什么 | 扫码记录查看 →「TSV 原文」→ 选日期/柜号，或直接搜条码（含回收站）；也可安装独立 TSV 阅读器，在文件管理器直接打开 |
| 文件管理器点 TSV 没有「TSV 阅读器」 | 安装 `成品出库_TSV阅读器_v1.0.0.apk`；点文件后选「打开方式」；仍没有就用阅读器内「选择 TSV 文件」 |
| 独立阅读器能改/删记录吗 | 不能，只读；删除仍在主 App 的扫码记录页操作 |
| 语音不朗读 | 检查「震动和声音设置」语音开关；调高媒体音量 |
| 导出失败 | 确认已授权「所有文件访问」，且存储空间充足 |
| 新 PDA 没有规则 | 配对电脑后「下载并覆盖本机规则库」；或拷贝规则库 XLSX 后在规则库点「导入」 |
| 换柜 / 补装 | v1.11.0 起已装齐后返回设置会清空柜号/计划/规则，可直接录入下一柜；同一柜补装时改大计划并重新添加规则再装柜（未装齐返回则原样保留） |
